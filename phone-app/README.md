# Altbot phone app

Fake-money crypto trading bot that runs in your phone's browser.
Live Binance prices, $1,000 paper wallet, coin picker, two trading methods, safety limits.

- Open the web address, then Chrome menu ⋮ → **Add to Home screen**.
- Trades only happen while the app is open on screen (phones pause web apps in the background).
- No API keys, no real money. All data stays on your phone.
